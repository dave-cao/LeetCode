# 15. 3Sum

## Notes
<small><i>Intuition and thought process in solving the question.</i></small>

I actually really liked this question. It combined a previous twosum question (basically sorted two-sum with pointers) and the actual two-sum question to solve this. We had to break this down, first sort it and then use a number and find the targets for that number (basically two sum.)

What I did was sort the numbers, then created a helper function (two_sum) and passed in the negative version of the number as the target and the rest of the list as the two_sum parameters. Then I got the two sum argument solutions list!

## Code
<small><i>The solution.</i></small>

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        """O(n^2) solution I think"""
        sorted_nums = sorted(nums)
        solutions = set()
        for i in range(len(sorted_nums)):
            num = sorted_nums[i]
            target = num * -1
            two_sum = self.twoSum(sorted_nums[i + 1:], target)
            if len(two_sum) != 0:
                for solution in two_sum:
                    triplet = (num, solution[0], solution[1])
                    solutions.add(triplet)
        return list(solutions)



    def twoSum(self, nums: list[int], target: int) -> list[int]:
        """O(n)"""
        left_pointer_i = 0
        right_pointer_i = len(nums) - 1

        solutions = set()
        while left_pointer_i < right_pointer_i:
            left_num = nums[left_pointer_i]
            right_num = nums[right_pointer_i]

            num_sum = left_num + right_num
            if num_sum == target:
                solutions.add((left_num, right_num))
            if num_sum > target:
                right_pointer_i -= 1
            else:
                left_pointer_i += 1
        return list(solutions)


    def threeSum_brute(self, nums: list[int]) -> list[list[int]]:
        three_sums = []
        for first_i in range(len(nums) - 2):
            for second_i in range(first_i + 1, len(nums) - 1):
                for third_i in range(second_i + 1, len(nums)):
                    first_num = nums[first_i]
                    second_num = nums[second_i]
                    third_num = nums[third_i]
                    total_sum = first_num + second_num + third_num
                    if total_sum == 0:
                        triplet = sorted([first_num, second_num, third_num])
                        if triplet not in three_sums:
                            three_sums.append(triplet)
        return three_sums
```
